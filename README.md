# Marigold Coffee Roasters

A demo coffee-shop landing page built with plain HTML, CSS and JavaScript (no frameworks). It accompanies the YouTube tutorial "Build a Stunning Website From Scratch (HTML, CSS & JavaScript)".

Open `index.html` in a browser. Fonts (Fraunces, Inter) are optional; add this inside `<head>` above the stylesheet:

```html
<link href="https://fonts.googleapis.com/css2?family=Fraunces:ital,opsz,wght@0,9..144,100..900;1,9..144,100..900&family=Inter:wght@400..700&display=swap" rel="stylesheet">
```

Features: sticky header, scroll progress, shop filter, add-to-bag, brew calculator, dark mode, FAQ, form validation, responsive menu.

"Marigold Coffee", prices and numbers are made-up placeholders. The newsletter form is a front-end demo.
